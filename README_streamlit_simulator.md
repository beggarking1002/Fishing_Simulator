# Balance Simulator (Streamlit)

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Expected files in the same folder
- Restaurant_Data_v.0.1.2.ods
- Fishing_Data_v.0.1.2.ods
- Guest_Data_v.0.1.2.ods

## Notes
- This prototype is an **expected-value simulator**, not a full event-by-event random simulation.
- It is meant for checking balance direction, bottlenecks, and upgrade efficiency quickly.
